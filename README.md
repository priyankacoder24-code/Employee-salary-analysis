# Employee Salary Analysis

## Project Overview

Employee Salary Analysis is a data analytics project focused on analyzing employee salary patterns using Python, SQL, PostgreSQL, and Power BI.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- PostgreSQL
- SQL
- Power BI
- Google Colab

## Project Workflow

Raw Dataset → Data Cleaning → EDA → PostgreSQL → SQL Analysis → Power BI Dashboard

## Data Cleaning

The dataset was cleaned using Python and Pandas.

Key steps:

- Missing value handling
- Duplicate removal
- Department and job role cleaning
- Experience-level creation
- Data validation

Final cleaned dataset contains 500 employee records.

## SQL Analysis

SQL was used for:

- Average, minimum and maximum salary
- Department-wise salary analysis
- Experience-level salary analysis
- Job-role salary analysis
- Gender-wise salary analysis
- Education-wise salary analysis
- Salary vs experience analysis
- Top 10 highest-paid employees
